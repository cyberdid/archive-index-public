# Пакет для завершення публікації

Текст статті завершено для авторського огляду: EN — 36 сторінок, UK — 38.
Джерела, числові твердження, шрифти, посилання та всі сторінки перевірено
машинними засобами. Це не авторське схвалення і не завершений людський аудит
релевантності; останній свідомо не входить у цю версію.

## Що підготовлено

- `zenodo-preprint.proposed.json`: запропоновані метадані препринту. Схема полів
  звірена з [офіційною документацією Zenodo](https://developers.zenodo.org/#deposit-metadata)
  23 жовтня 2026 року. API-перевірку або подання не виконано. Пропозиція — один
  запис з англійським текстом та українською версією; остаточне рішення за автором.
- `author-decisions.json`: лише справжні невирішені авторські питання.
  Ліцензії підтверджені автором: CC BY 4.0 для статті й оригінальних записів,
  Apache-2.0 для коду. Фінансування, конфлікти інтересів і наукове схвалення
  залишаються окремими авторськими деклараціями.
- Локальний компактний архів містить поточний код, результати JSON, тексти,
  таблиці, рисунки й PDF. Його точний склад та SHA-256 записані в
  `paper/results/publication_package_verification.json`.

## Перед відкритою публікацією

1. Прочитати обидві версії й підтвердити авторські дані, висновки, джерела та
   декларації. Заповнити відповідні поля `author-decisions.json`.
2. Ліцензії обрано за зразком попередніх статей: Apache-2.0 для коду, CC BY 4.0
   для тексту та оригінальних експериментальних записів. Для публікації
   лише PDF не потрібно поширювати весь корпус або приватний резервний архів.
3. Погодити точні публічні файли та схему записів Zenodo. Після отримання
   реальних ідентифікаторів замінити видимі DOI/URL-позначки в обох текстах,
   оновити CITATION.cff, перебудувати й повторно перевірити PDF та пакет.
4. Опублікувати тільки погоджений окремий експорт. Поточний приватний Git-репозиторій
   та його історію залишити приватними. Для поширення сирого корпусу окремо
   завершити перевірку сторонніх прав та атрибуції.

Канонічний `candidate-006` лишається незмінним знімком експериментів і повного
статистичного відтворення; його попередні PDF не є поточною редакцією статті.
Компактний новий архів відтворює таблиці й PDF зі збережених результатів, але
не містить сирого корпусу, векторних кешів, ваг моделей, приватних запитів чи
повних frozen-input даних для всіх 14 етапів. Їх не слід удавати включеними.

Метадані не містять DOI попередніх статей автора як ідентифікаторів цієї роботи.
Жодного запису Zenodo не створено, DOI не зарезервовано. Ліцензії застосовано
за прямим рішенням автора. Окремо автор дозволив GitHub Release в існуючому
публічному репозиторії `cyberdid/archive-index-public`.
